# 📂 UKK 2526 – Multi Branch Project

Repositori ini berisi beberapa aplikasi yang dipisahkan berdasarkan **branch**.
Setiap branch mewakili proyek atau modul yang berbeda.

## 📌 Daftar Branch

| Branch                   | Deskripsi                                         |
| ------------------------ | ------------------------------------------------- |
| `main`                   | Branch utama, berisi informasi umum & dokumentasi |
| `aplikasi_ppdb`          | Aplikasi PPDB                                     |
| `aplikasi_sid`           | Aplikasi Sistem Informasi Desa                    |
| `aplikasi_bk`            | Aplikasi Bimbingan Konseling                      |
| `aplikasi_bengkel_mobil` | Aplikasi Bengkel Mobil                            |

> **Catatan:** Repository ini memiliki banyak branch. Disarankan untuk clone hanya branch yang dibutuhkan agar lebih cepat dan tidak memuat branch lain.

---

## 🔄 Cara Clone Single Branch

Gunakan perintah berikut untuk clone hanya satu branch:

```bash
git clone --branch <nama_branch> --single-branch <url_repo>
```

**Contoh:**

```bash
git clone --branch aplikasi_ppdb --single-branch https://github.com/username/ukk2526.git
```

Setelah proses clone selesai, masuk ke folder project dan ikuti instruksi setup sesuai branch tersebut.
